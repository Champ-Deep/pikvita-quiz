Method 1: Script Embed (Recommended)

This method gives you full control with callbacks and analytics tracking.

<!-- Add the container --> <div id="pikvita-quiz"></div> <!-- Load the embed script --> <script src="pikvita-quiz.js"></script> <!-- Initialize with options --> <script> PikvitaQuiz.init({ containerId: 'pikvita-quiz', apiEndpoint: 'http://localhost:3000/api/quiz-responses', source: 'example-page', onComplete: function(data) { console.log('Quiz completed!', data); alert('Thanks for taking the quiz, ' + data.persona + '!'); }, onStepChange: function(data) { console.log('Step changed to:', data.step); } }); </script>

Method 2: Direct iFrame Embed

Simple and straightforward—just paste this code anywhere on your page.

<iframe src="pikvita-quiz-embed.html?api=YOUR_API_ENDPOINT&source=iframe" width="100%" height="800px" frameborder="0" style="border-radius: 24px; box-shadow: 0 10px 40px rgba(139, 90, 43, 0.15);" ></iframe>

Method 3: Auto-Initialize

The script automatically initializes when it finds elements with the data-pikvita-quiz attribute.

<div id="my-quiz" data-pikvita-quiz data-api-endpoint="https://api.pikvita.com/api/quiz-responses" data-source="blog-post" data-width="100%" data-height="800px" ></div> <script src="pikvita-quiz.js"></script>
